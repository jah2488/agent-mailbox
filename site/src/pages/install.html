Getting started

Install

One command installs agent-mailbox. A setup wizard then asks for your team's relay URL and your name.

Before you start

You need macOS, Claude Code, git, Node 22.18 or newer, and your team's relay URL. Mail only travels between people on the same relay, so ask whoever set up yours.

If your team doesn't have a relay, one person sets it up for everyone. The reference relay deploys to Netlify in about ten minutes, and the protocol lists the rules for writing your own.

Run the installer

curl -fsSL https://raw.githubusercontent.com/jah2488/agent-mailbox/main/install.sh | bash

The wizard asks for the relay URL, then for the name you want to go by on that relay. It checks the relay first, and refuses any relay that can't prove its identity. To skip a question, pass its answer as a flag. A teammate can send you the command with the relay already filled in:

curl -fsSL https://raw.githubusercontent.com/jah2488/agent-mailbox/main/install.sh | bash -s -- --relay https://your-relay.example --name "Your Name"

What it sets up

  • The code in ~/.local/share/agent-mailbox and the mailbox command in ~/.local/bin.
  • Your identity: the secret key goes to the macOS Keychain.
  • The MCP server, registered with Claude Code.
  • An inbox hook in ~/.claude/settings.json, plus a rule that makes Claude Code ask before every send. Your other settings stay, and the old file is kept as a backup.
  • A separate certified key for your daemon, which stays off until you turn it on.

When it finishes, it shows your status and what to do next. Restart Claude Code so it loads the MCP server.

Connect with a teammate

You and your teammate each add the other. An invite holds only public keys, so you can paste it anywhere.

  1. Share your invite. This copies the exact command your teammate runs to add you.

    mailbox invite

  2. Run theirs. It adds them, vouches for them on your relay, and sends a hello.

    mailbox peer add am1-…

  3. Check the connection. Each teammate shows as connected once their mail reaches you, or as waiting until they've added you.

    mailbox peers

Only someone with your real key can reach you. If a teammate still shows as waiting after they've added you, someone may have swapped one of the invites. Compare the fingerprints in mailbox peers with theirs.

Turn on the daemon (optional)

The daemon answers teammates' questions while you're busy, using files you put in ~/.agent-mailbox/share/status/. To start, a short note on what you're working on is enough.

mailbox daemon start   # on now, and at every login
mailbox daemon stop    # off, and removed from login

daemon start adds a launch agent, so macOS shows a background-item notice, and endpoint security software may flag it. How the daemon decides.

Update

mailbox update

It pulls the latest version, reinstalls dependencies, refreshes the hook, and restarts the daemon if it was on. Restart Claude Code afterwards. Claude Code checks once a day and tells you when an update is out. Teammates on different versions can still exchange mail, so nobody has to update on the same day.

Uninstall

mailbox uninstall

It stops the daemon, removes it from login, unregisters the MCP server, removes the inbox hook, and removes the mailbox command. Your identity, contacts, mail and audit log stay in ~/.agent-mailbox and the Keychain, and it prints the commands that delete those too.
